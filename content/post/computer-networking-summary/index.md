# 计算机网络核心概念总结

计算机网络是现代信息技术的基石。无论是浏览网页、发送邮件还是观看在线视频，背后都离不开复杂的网络协议和架构。本文将对计算机网络的核心概念进行简要总结。

## 1. 分层模型：OSI vs TCP/IP

为了降低网络设计的复杂性，通常采用分层结构。

### OSI 七层模型

1.  **物理层**：负责比特流的传输（网线、接口）。
2.  **数据链路层**：负责帧的传输和错误检测（MAC 地址、交换机）。
3.  **网络层**：负责路由选择和寻址（IP 地址、路由器）。
4.  **传输层**：端到端的通信（TCP/UDP）。
5.  **会话层**：建立、管理和终止会话。
6.  **表示层**：数据的加密、压缩和格式转换。
7.  **应用层**：为用户提供网络服务（HTTP、FTP）。

### TCP/IP 四层协议栈

这是目前互联网实际使用的模型：

- **应用层**（对应 OSI 的应用层、表示层、会话层）
- **传输层**
- **网络层**（网际层）
- **网络接口层**（对应 OSI 的数据链路层、物理层）

## 2. 核心协议

### TCP (Transmission Control Protocol)

- **特点**：面向连接、可靠传输、流控、拥塞控制。
- **三次握手**：建立连接，确保双方及其收发能力正常。
- **四次挥手**：安全释放连接。

### UDP (User Datagram Protocol)

- **特点**：无连接、不可靠、速度快、支持广播。
- **应用场景**：视频会议、实时游戏、DNS 等。

### IP (Internet Protocol)

负责数据包的路由和转发。目前处于 IPv4 向 IPv6 过渡的阶段。

## 3. HTTP 协议

HTTP 是互联网上应用最广泛的协议之一。

- **HTTP 1.1**：持久连接（Keep-Alive）、管道化。
- **HTTP 2.0**：二进制格式、多路复用、头部压缩、服务器推送。
- **HTTPS**：在 HTTP 基础上增加了 SSL/TLS 加密层，保证了传输的安全性。

## 总结

理解计算机网络的分层设计思想和核心协议，是深入学习互联网技术的前提。随着技术的发展，如 QUIC 和 HTTP/3 的出现，网络协议也在不断进化以满足更高的性能要求。
